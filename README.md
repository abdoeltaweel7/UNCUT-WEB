# Uncuts Production

A cinematic Next.js site built as a seven-act journey. Start it locally with `npm install` and `npm run dev`.

## Edit the content

- `data/siteConfig.ts` — company identity, contact details and navigation
- `data/services.ts` — service names, copy and scene images
- `data/projects.ts` — portfolio works and project metadata
- `data/partners.ts` — success partner names/logos
- `app/globals.css` — the central `:root` theme variables and all visual styling

Replace each remote image URL in the data files with a project image in `public/` when final photography is ready.
